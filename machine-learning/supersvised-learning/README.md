## Supervised learning
Supervised Learning is a type of Machine Learning where a model learns from labeled data.
> Labeled data is data that already comes with the correct answer attached.

Simple idea. Each example has:

- Input (X) → the data
- Label (Y) → the correct output

So the model knows what the right answer is while learning.

Examples: 
- Image of a cat → label: `cat`
- Email text → label: `spam` or `not spam`
- House features → label: price (e.g., $300,000)
