### what am I using?
**scikit-learn** is a Python library for Machine Learning that helps you build models without coding everything from scratch.
Instead of writing complex math yourself, `Scikit-learn` gives you ready-to-use tools to:

- train models
- make predictions
- evaluate results


### Components of Scikit-learn

## Numpy
Working with numbers and arrays

- Handles large datasets efficiently
- Provides multidimensional arrays (like tables of numbers)
- Supports fast mathematical operations

## Scipy
Adds more advanced math tools.

- Optimization (finding best solutions)
- Linear algebra
- Statistics
- Signal processing


## Matplotlib
To create graphs and visualizations

- Plot charts (line, bar, scatter, etc)
- Visualize data and model results
- Helps understand patterns

# Cython
Mixes python and c

- speeds up python code
- compiles python into c for better performance
